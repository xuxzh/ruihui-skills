# 禅道地址进版本库、技能走公网分发、凭据默认账号密码

禅道 MCP 与禅道 Web 的地址用内网 IP 写在技能包的 `config.local.json` 里，该文件**进仓库**、随技能包一起分发；技能的主分发渠道是公网 `skills.sh`（`npx skills add xuxzh/ruihui-skills --skill rh-product-feedback --global`）；接入凭据默认用「禅道账号 + 密码」，令牌可选而非首选。这一条修订 ADR-0002 与 ADR-0004 里「地址随内部分发包发出、不进仓库」「优先用令牌」的部分。

## 考虑过的选项

- **地址留在内网分发包，公开仓库只放占位符**（原方案）：公开面最小，但公开包与内网包要维护两套分发路径，且从公网装到的技能没有地址、装完不能用。
- **用内网域名代替 IP**：能顺带解决「IP 随网络调整失效」，但公司没有可指禅道 MCP 的内网 DNS 域名，不具备落地条件。
- **进内网 Git 仓库、公开仓库只发公开版**：两套源并存，`skills.sh` 装到的仍是无地址版本，用户仍要额外一步。
- **地址进仓库、走公网分发**（采用）：一条命令装完就有地址可用，代价是内网地址在公开仓库里长期可见。

## 后果

- 内网地址（含 IP 与端口）随仓库永久公开、不可撤回；`192.168.x.x` 不从公网可达，攻击面仍限于内网，但内网拓扑从此是公开信息。
- 仓库的敏感信息扫描规则改为**按路径放行**：内网地址只允许出现在 `skills/rh-product-feedback/config.local.json`，出现在其它任何文件仍判 fail；「`config.local.json` 必须在 `.gitignore` 里」这条断言反过来变成「必须已纳入版本库」。
- 技能硬约束 9 从「内网地址不进文档、不进提交记录」改为「凭据不进文档与提交记录；地址可读但不主动回显」。技能对地址的读取来源不变。
- 「内网版技能包 / 公开版技能包」这组区分作废，只剩一份带真实地址的包；GLOSSARY 改用「接入配置」指 `config.local.json`。
- 业务用户用密码而不是令牌：少一步「去禅道生成令牌」的操作；代价是密码比令牌难单独撤销，且泄露面相同（会话登录下都会进入 Agent 上下文）。令牌仍支持。
- 禅道 MCP 若改为按用户凭据登录，本 ADR 的凭据选择不需改；届时「每用户独立账号」（ADR-0001）才真正成立。
